# MoviePilot-TaskConfirmPlugins

[MoviePilot V3](https://github.com/jxxghp/MoviePilot) 自定义插件仓库（个人用）。

## 插件列表

| 插件 | 说明 |
|---|---|
| **TaskConfirmMax 任务确认中心 Max** | **一体化 Max 版：确认中心 Web 服务内嵌进插件**，容器内默认监听 `0.0.0.0:8005`，页面 `/ui/pending`；指令框**直接输入搜索词**（无需前缀）；选媒体 → 选站点资源 → 自动/指定下载器下载，三阶段闭环。专配 MoviePilot，无需外部确认中心。 |
| TaskConfirmBridge 任务确认桥接 | 旧版：依赖外部部署的「任务确认中心」，把指令框的 `mp <搜索词>` 转成 MP 媒体搜索。两者功能重叠，**二选一启用即可**。 |

## 安装

MoviePilot → 设定 → 插件 → 插件市场，加入本仓库地址：

```
https://github.com/huiyi977/MoviePilot-TaskConfirmPlugins
```

刷新后即可在「在线插件」里安装 **任务确认中心 Max TaskConfirmMax**。

## Max 版部署要点

1. **端口映射**：插件在 **MP 容器内** 监听 8005，需要在 MP 容器上追加端口映射：
   `8005:8005`（主机端口可自定，若与宿主机已有 8005 冲突就映射成 `8006:8005`，
   并把插件的「对外访问地址」配成 `http://<主机IP>:8006`）。
2. **通知**：v2.2.0 起内置直推，不再依赖任何外部脚本。插件配置里按渠道填：
   - Bark：服务器（默认 `https://api.day.app`）+ DeviceKey
   - 企业微信机器人：完整 Webhook URL
   - Gotify：地址 + Token
   通知渠道 `wecom` / `bark` / `gotify` / `all`（all 三渠道全发）；
   凭证只存在插件配置里，代码不含任何个人信息。
3. **页面访问**：`http://<主机IP>:<映射端口>/ui/pending`；若配置了 `api_token`，
   页面链接需带 `?token=<api_token>`（通知里的链接会自动带上）。

## Max 版使用

打开页面，在指令框**直接输入搜索词**（无需 `mp` 前缀）：

```
蜘蛛侠
```

- **阶段 1**：候选卡片（标题/年份/类型/评分/简介），点选进入下一阶段
  - 选中的媒体会**先查媒体库**（Emby/Jellyfin/Plex…，开关默认开）：已在库 → 推送一条通知并**终止**，
    不再搜资源/下载；不在库 → 继续阶段 2
- **阶段 2**：站点资源卡片（`标题｜大小｜站点｜⬆做种｜🆓免费`），点选进入下一阶段
- **阶段 3**：自动调用 MP 默认下载器下载（可在插件里关闭，改为推送下载器选择卡片）

卡片右上角有「撤回」按钮（两段确认）；页面右上角 ❓ 是指令帮助、📜 是历史记录。

## Bridge 版配置（旧版）

| 配置项 | 默认 | 说明 |
|---|---|---|
| 中心地址 | `http://192.168.5.126:8005` | 任务确认中心服务地址 |
| 中心 token | 空 | 确认中心配置了 api_token 时填写 |
| 候选上限 | 8 | 推回确认中心的候选条数上限 |
| 任务有效期 | 3600s | 确认任务超时时间 |
| 收割窗口 | 21600s | 用户点选后插件等待收割的最长时间 |
